# Executive Command Centre

Version-controlled operating layer for Exclusion Systems / BannedBand.

## System of record
- **Portfolio, actions, decisions and risks:** Google Drive → Executive Command Centre → Executive Portfolio Register.
- **Evidence and working documents:** Google Drive → Executive Command Centre.
- **Versioned specifications, operating documents and handoff templates:** this repository.

## Operating cycle
1. Capture work in the Portfolio Register.
2. Assess impact, urgency, dependencies, risk and evidence required.
3. Assign work to the appropriate AI role.
4. Store durable project outputs in Drive and versioned operating assets here.
5. Record decisions, deadlines and follow-ups in the register.
6. Review priorities weekly.
